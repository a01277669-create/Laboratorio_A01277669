Tic Tac Toe - Mejoras del Proyecto

Nombre: Marco
Matrícula: A01277669


Este proyecto consiste en la implementación y mejora del videojuego Tic Tac Toe utilizando Python y la librería Turtle Graphics. El código base fue tomado del sitio de Grant Jenks y posteriormente modificado para cumplir con los requerimientos de la actividad.

Se realizaron diversas mejoras al juego original. En primer lugar, se modificó el diseño de los símbolos "X" y "O", ajustando su tamaño, color y posición para que quedaran correctamente centrados dentro de cada casilla, lo que mejora la claridad visual del juego.

Posteriormente, se implementó una validación para evitar que un jugador pueda colocar su símbolo en una casilla que ya se encuentra ocupada. Esto se logró mediante el uso de un diccionario que almacena el estado del tablero.

También se desarrolló una función que permite detectar cuando un jugador gana, evaluando todas las posibles combinaciones de victoria, incluyendo filas, columnas y diagonales. Cuando se cumple una de estas condiciones, el sistema identifica al ganador y lo indica en la consola.

Finalmente, se añadió la lógica necesaria para detectar un empate, el cual ocurre cuando todas las casillas están ocupadas y no existe un ganador.

El desarrollo del proyecto se llevó a cabo utilizando control de versiones con Git. Se trabajó en una rama individual donde se realizaron commits por cada mejora implementada, siguiendo buenas prácticas en la redacción de mensajes. Posteriormente, los cambios fueron integrados a la rama principal del repositorio.

Se utilizaron tecnologías como Python 3, Turtle Graphics, Git y GitHub para el desarrollo del proyecto.
